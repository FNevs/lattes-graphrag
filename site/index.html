        Conceitos

        Este grafo foi gerado pelo GraphRAG (Microsoft) a partir do texto dos currículos Lattes. Um modelo de linguagem leu cada trecho e anotou o que existe (entidades) e como as coisas se ligam (relações). Nada aqui é digitado à mão: tudo foi extraído do texto.

        Estrutura do grafo

        Entidade (nó)
        Uma coisa que o currículo cita: uma pessoa, um artigo, um projeto, uma instituição. Cada bolinha.
        Relação (aresta)
        Uma ligação que o texto afirma entre duas entidades — por exemplo, "fulano é autor do artigo X". Cada linha. Passe o mouse sobre ela para ler a frase que a justifica.
        Conexões (grau)
        Quantas relações uma entidade tem. Define o tamanho do nó: quanto maior, mais ligada.
        Menções
        Em quantos trechos do texto a entidade apareceu. Alguém pode ser muito mencionado e pouco conectado.
        Entidade isolada
        Foi extraída, mas o texto não a liga a nada — por exemplo, um autor cuja produção ficou em outro trecho.
        Em 2+ currículos
        Entidades citadas por mais de um pesquisador. São as pontes do grupo: coautorias, projetos e eventos em comum.

        Tipos de entidade

        Comunidades

        Comunidade
        Um grupo de entidades mais ligadas entre si do que com o resto, encontrado pelo algoritmo de Leiden. Costuma corresponder a uma linha de pesquisa ou a um projeto.
        Nível
        As comunidades são hierárquicas. O nível 0 tem poucos grupos grandes; níveis maiores quebram cada grupo em partes menores e mais específicas.
        Relatório de comunidade
        Um resumo em texto que o modelo escreveu para cada comunidade. É o que a busca "global" do GraphRAG usa para responder perguntas sobre o conjunto.

        Leituras e cuidados

        Produções em comum
        Na visão geral, a linha entre dois pesquisadores conta produções ligadas aos dois (pessoa → produção ← pessoa). O modelo não cria aresta direta entre coautores: a coautoria aparece pela produção que a justifica.
        Variantes de nome
        A mesma pessoa pode aparecer como vários nós ("HUGO SABA", "HUGO SABA PEREIRA CARDOSO"). O GraphRAG não unifica grafias. É uma limitação conhecida e medida no TCC.
        Versão
        Cada versão é uma indexação diferente do experimento (modelo, prompt, formato do texto, número de currículos). Trocar de versão permite comparar o efeito de cada mudança.

        Como navegar

        • Visão geral: os pesquisadores e quantas produções cada par divide.
        • Clique num pesquisador para ver a rede dele em caixas por tipo.
        • Clique em qualquer nó para centralizá-lo; o botão ← Voltar desfaz o passo.
        • Arraste um nó para reorganizar o espaço; a caixa do tipo acompanha.
        • Arraste as bordas das colunas para dar mais espaço ao grafo ou ao painel.
        • Exploração livre: o grafo inteiro, com filtros de conexões e de quantidade.
